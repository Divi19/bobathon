    How it works

    Data source

    Hourly temperature, humidity, solar radiation and day/night flag from Open-Meteo (free, no API key, no account required).

    WBGT calculation (Stull 2011 model)

    Step 1 — Wet-bulb temperature (Stull 2011, angles in radians):
    Tw = T·atan(0.151977·√(RH+8.313659)) + atan(T+RH) − atan(RH−1.676331) + 0.00391838·RH^1.5·atan(0.023101·RH) − 4.686035

    Step 2 — WBGT shade: wbgtShade = 0.7·Tw + 0.3·T

    Step 3 — Solar correction (rule-of-thumb estimate): WBGT = wbgtShade + (inSun && isDay ? 3·min(radiation/800, 1) : 0)

    ⚠ The solar correction is a simplified estimate. It does not account for cloud cover variation or wind speed. Night-time values (🌙) use shade WBGT only. This tool gives general guidance, not precise occupational measurements.
